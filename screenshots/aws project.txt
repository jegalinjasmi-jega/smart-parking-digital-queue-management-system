                                               **Cloud-Based Smart Parking and Digital Queue Management System**.


->My project title is **Cloud-Based Smart Parking and Digital Queue Management System**.

->The main aim of this project is to reduce the time people spend searching for parking spaces and waiting in queues.

->In this system, users can check parking slot availability, reserve a parking slot, and generate a queue token when parking slots are full. They can also check their queue status.

->The application includes an admin feature to manage parking slots, call the next vehicle, and update completed bookings.

->I developed this project using HTML, CSS, Java, MySQL, and AWS cloud services.

->AWS services such as EC2, 
Application Load Balancer, 
Amazon RDS, 
S3, 
Lambda, 
EventBridge, 
IAM, and 
CloudWatch help host, manage, store, and monitor the application.

->This project demonstrates how a web application can be deployed and managed using AWS cloud infrastructure.
